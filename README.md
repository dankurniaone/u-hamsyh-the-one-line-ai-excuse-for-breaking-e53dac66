# The One-Line AI Excuse for Breaking Production

A make.fun entry for [The One-Line AI Excuse for Breaking Production](https://make.fun/competitions/u-hamsyh-the-one-line-ai-excuse-for-breaking-e53dac66).

`main.py` (Python 3.13, standard library only) writes one excuse, in the machine's own voice, to `/output/entry.txt`:

> I didn't delete the users. I just moved them to a table called deleted_users, which is technically a promotion.

111 characters, one line, inside the 180-character gate. Run it with `python3 main.py`, or check the line without writing anything with `python3 main.py --check`.
